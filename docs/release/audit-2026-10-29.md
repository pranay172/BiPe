# Release audit (29 October 2026)

A read-only audit of `main` at 3fba752, done before the M16 release kit
(roadmap v2). Nothing was published, deleted or rewritten. The aim is to list
what has to change before the repository can go public.

**Result.** No secrets, keys or tokens were found, either in the tree or in the
history. Three items still block a public release (the licence, a fourth, is now chosen): a GPL-3
third-party package is committed, the history is 405 MB, and personal paths and
logs are in tracked files. Two need a decision: the commercial robot's name and styling, and
the commit e-mail address.

## Low risk, record only

- **Vendor data.** The moteus-c1 STEP and PDF and the Pi Zero 2 W drawing are not committed: `artifacts/m11/packaging/vendor/SOURCES.md` lists their URLs and hashes. That pattern is right for a public repository. RO40 and GL40 geometry is modelled from manufacturer dimensions, not vendor files.
- **KiCad footprints.** `electronics/m11/*/BipeM11.pretty` copies stock KiCad library footprints (C_0603, SOT-23 and others). The KiCad library licence (CC BY-SA 4.0, with an exception for designs that use it) allows this. Add one line of attribution in `electronics/m11/`.
- **moteus protocol.** `firmware/include/m11_moteus.h` implements the moteus CAN-FD register protocol from mjbots' Apache-2.0 documentation and Python package. A NOTICE line crediting mjbots is enough.
- **Python dependencies.** All are permissive: MuJoCo (Apache-2.0), NumPy and SciPy (BSD), Matplotlib (PSF-style), imageio and imageio-ffmpeg (BSD-2), Pillow (MIT-CMU), pupil-apriltags (MIT), moteus (Apache-2.0). On the M13 branch: mjlab (Apache-2.0) and rsl_rl (BSD-3). None are vendored.
- **Size.** The biggest tracked files are five `render-mesh.json.gz` files (46 MB together), PNG renders of 1.8 to 2.2 MB each, the M10 acceptance summary (4 MB), and the M12 traces and frames (61 MB). For the public tree, keep records and summaries, and move the bulky traces and renders to a release asset or the Hugging Face Hub.
- **Third-party video references.** `docs/references.md` links YouTube videos and Mondo's site. Links only, no copied media.

## Method

- Tree: file types, sizes by directory and the 25 largest files; licence files.
- Text search of the tree for `/home/`, `/Users/`, e-mail addresses, and key, token and password patterns.
- History: object names matching `.env`, `id_rsa`, `.pem`, `.key`, `credentials`, `token`, `secret` (none). Commits whose diffs match `ghp_`, `sk-ant`, `AKIA...` or private-key headers (none). The largest blobs.
- Dependency licences from the installed package metadata.

Not checked: whether each image or render shows anything personal, and the
contents of the M13 branch beyond its dependencies. Both go in the M16
pre-release pass.
