The adopted packaging model is 2.494762 kg with only 5.238 g below its 2.5 kg ceiling. All 27 C-controlled contact-physics cases and the saved uncertainty suite pass under their stated assumptions. The internal resistor spreader lacks a justified ambient heat path. The existing power PCB demonstrates connectivity, not current capacity. Exact AK40 V3 / AK48 electrical and command fields are incomplete; BMS/fuse volumes are provisions. Preserve those outputs and the user's separately saved M3 native CAD bytes.

## Implementation order

1. Refresh exact-variant primary-source evidence. Retrieve current manufacturer downloads, compare hashes and record each field as documented, inferred, assumed or unknown. Select a specific 6S protection/fuse/connector candidate using published dimensions, voltage/current/charge thresholds and computed load needs. Check fit against the actual selected board; a failed fit is retained, not labeled solved. Prepare requests for missing evidence without sending them.
2. Implement a thermal design study with an explicit route from resistor case to external ambient: compare a bridge to an exposed metal panel, a replacement panel and bounded slower braking duty. Include resistor-to-case pulse rise, contact/conduction resistance, finite metal heat capacity, ambient corners, other heat loads and energy/time histories. Reproduce the known failed internal-spreader case as a negative control. Calculate a proposed event interval and fail-safe temperature/energy limits. Manufacturer pulse and contact data bound what can be claimed; an assumed convection coefficient is not hardware qualification.
3. Create a native CAD thermal/pack candidate, save clearances, contact area, containment, attachment/removal assumptions and STEP/native round-trip checks. Reconcile material removals/additions, PCB copper, pack protection and hardware once. Adopt physical changes only when mass budget, CAD and declared structural checks pass; then run the full 27-case C acceptance, timestep convergence and relevant uncertainty/fault regressions with saved configuration and source fingerprints.
4. Revise the power PCB using explicit power paths, short gate routing and Kelvin shunt sense. Define current domains from the conservative protection thresholds rather than nominal locomotion alone. Compute copper/neck/via/wire/connector loss and thermal screening at specified copper thickness, length and current; save topology and bottleneck checks tied to native geometry. Run native ERC, DRC, connectivity and pin/value checks. Analyze reverse polarity, fuse coordination and inductive suppression with selected-device primary evidence. Behavioral circuit results remain conditional where device SOA, ripple or exact motor limits are not established.
5. Complete the reusable application boundary: timestamped sensor ingestion, calibration/startup, six-actuator scheduling, command profile gate, bus-off/stale/invalid feedback, explicit reset/rearm, bounded requests and watchdog heartbeat. Exercise it through a fake HAL using clearly synthetic protocol/profile values, then compile for the real MCU with real command/heartbeat permission inhibited. Tests must show an incomplete real profile cannot transmit operational commands or request power. Hardware calibration/timing/driver mapping remain distinct commissioning work.
6. Regenerate current electrical, thermal, fit/mass and application evidence, inventory hashes and documentation. Preserve the previous seal as a historical checkpoint. Record completed digital tasks separately from missing external documentation and future physical qualification. Make focused local commits at planning, implementation and verification checkpoints.

## Acceptance and stop conditions

- Thermal calculation conserves energy, reproduces independent analytical limits and includes negative/overload cases. A passing conditional duty bound is labeled with ambient, pulse, interface and heat-load assumptions; no temperature guarantee is inferred from an envelope.
- Selected pack/protection/fuse dimensions and limits have manufacturer evidence or remain explicitly unqualified. No candidate is adopted on a guessed board size, missing charge protection, or an unexplained negative mass allowance.
- A proposed physical revision has valid solids, intentional thermal contact, no unintended intersections, saved mass properties and the same free-base/finite-effort/physical-contact acceptance conditions. A failed candidate leaves the accepted robot model intact.
- Power routing is checked using its saved native copper geometry. ERC/DRC/connectivity alone cannot pass the current-rating gate. Fine-pitch stubs, protection tolerance, via paths, shunt/gate loops and harness transient limits are visible in the report.
- Application tests cover stale sensors, duplicate IDs, wrong calibration, profile failure, deadline/bus-off, operator stop, wrap and restart. Host warning/sanitizer and MCU builds pass; no hardware image enables an unqualified profile.
- If exact AK48 limits or real device/pack data remain unavailable, finish independent implementation and provide a concrete evidence request. M4 completion stays false for unresolved required gates; distinguish missing documentation from tools that are functioning.
